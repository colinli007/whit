## MODIFIED Requirements

### Requirement: 多标签

编辑区 SHALL 可以同时打开多个标签。标签有三种：

- **文件标签**：显示文件内容，可编辑。
- **diff 标签**：显示某个改动文件在某个分组下的 diff，只读。
- **设置标签**：显示设置页面（见 `settings-editor`）。

三种标签放在同一个标签栏里，同一时刻只有一个当前标签。

**不重复打开**：同一文件（以磁盘上的完整路径区分）SHALL 只有一个文件标签；同一分组下同一文件 SHALL 只有一个 diff 标签；整个窗口最多一个设置标签。再次打开已打开的文件、diff 或设置时，SHALL 切换到已有的标签，不新建标签。

**位置与滚动**：新标签 SHALL 插在当前标签的右侧。标签过多放不下时，标签栏 SHALL 可以横向滚动，且当前标签始终滚动到可见范围内。

**仓库外的文件**：文件标签 SHALL 也能打开仓库外的文件（目前的入口只有设置页面的「打开设置(JSON)」）。这类文件的编辑、保存、未保存判定和关闭前询问，与仓库内的文件相同。它们在磁盘上被修改或删除时，SHALL 按 `file-watching` 的「打开的文件被外部修改」「保存冲突」「打开的文件被删除」同样处理。它们不在资源管理器中定位，也不显示 git 状态。

#### Scenario: 同时打开文件和 diff

- **WHEN** 用户双击资源管理器中的 `a.rs`，再双击源代码管理「更改」组中的 `b.rs`
- **THEN** 标签栏有 `a.rs` 和 `b.rs (工作树)` 两个标签，当前标签是后者

#### Scenario: 不重复打开

- **WHEN** `a.rs` 已有文件标签且不是当前标签，用户在资源管理器中再次双击 `a.rs`
- **THEN** 切换到已有的 `a.rs` 标签，标签数量不变

#### Scenario: 文件标签和 diff 标签互不替代

- **WHEN** `a.rs` 已有文件标签，用户在「更改」组中打开 `a.rs`
- **THEN** 新增一个 `a.rs (工作树)` diff 标签，原来的文件标签保留

#### Scenario: 打开仓库外的 settings.json

- **WHEN** 用户在设置页面点击「打开设置(JSON)」，修改后按 ⌘S
- **THEN** `settings.json` 标签打开并可编辑，保存后标签上的未保存圆点消失，资源管理器中的选中项不变

#### Scenario: 仓库外的文件被外部修改

- **WHEN** `settings.json` 标签没有未保存修改，用户在终端修改了该文件
- **THEN** 标签中的内容在 1 秒内更新为磁盘上的新内容

### Requirement: 标签的外观

每个标签 SHALL 显示图标、标题、关闭按钮：

- 文件标签：标题是文件名。
- diff 标签：标题是 `<文件名> (工作树)` 或 `<文件名> (索引)`，后面跟状态字母。
- 设置标签：标题是「设置」，图标是设置图标。

打开的多个文件标签文件名相同时，SHALL 在标题后用较暗的颜色显示所在目录以便区分；仓库外的文件显示从 `~` 开始的目录。

- **当前标签**：使用主题的活动标签背景（与编辑区相同）和前景色；其它标签使用主题的非活动标签背景和前景色（VS Code 的 `tab.activeBackground` / `tab.inactiveBackground`）。标签之间以 `tab.border` 分隔。
- **关闭按钮**：当前标签上始终显示，其它标签上只在鼠标悬停时显示。
- **未保存的文件标签**：关闭按钮的位置显示一个实心圆点；鼠标悬停时，圆点变成关闭按钮。
- **悬停提示**：
  - 仓库内的文件显示完整相对路径；
  - 仓库外的文件显示从 `~` 开始的完整路径；
  - 设置标签显示「设置」。

#### Scenario: 未保存圆点

- **WHEN** 用户在 `a.rs` 中输入一个字符
- **THEN** `a.rs` 标签的关闭按钮变为圆点；鼠标移到标签上时，圆点变回关闭按钮

#### Scenario: 同名文件

- **WHEN** 打开了 `src/mod.rs` 和 `src/git/mod.rs` 两个文件标签
- **THEN** 两个标签分别显示为 `mod.rs src` 和 `mod.rs src/git`，目录部分颜色较暗

#### Scenario: 仓库外文件的悬停提示

- **WHEN** 鼠标停在 `settings.json` 标签上
- **THEN** 提示显示 `~/Library/Application Support/Whit/settings.json`

### Requirement: 关闭标签

用户 SHALL 可以通过以下方式关闭标签：标签上的关闭按钮、在标签上按鼠标中键、⌘W（关闭当前标签）。关闭当前标签后，系统 SHALL 激活最近使用过的另一个标签（VS Code `workbench.editor.focusRecentEditorAfterClose` 的默认行为）。关闭最后一个标签后，编辑区按 `workbench-layout` 的「编辑区」显示：已打开仓库时显示空白背景及简短提示，未打开仓库时显示欢迎页内容。

#### Scenario: 关闭后回到最近使用的标签

- **WHEN** 依次打开了 `a.rs`、`b.rs`、`c.rs` 三个标签，用户切回 `a.rs` 后按 ⌘W
- **THEN** 当前标签变为 `c.rs`（最近使用过的），而不是位置上相邻的 `b.rs`

#### Scenario: 关闭最后一个标签

- **WHEN** 已打开仓库且只有一个标签，用户点击它的关闭按钮
- **THEN** 编辑区显示空白背景和提示文字，面包屑和标签栏右侧的按钮都不显示

#### Scenario: 欢迎页上关闭设置标签

- **WHEN** 未打开仓库，只有「设置」标签，用户按 ⌘W
- **THEN** 标签栏消失，编辑区显示欢迎页内容
