## Purpose

按 VS Code 工作台的样式组织窗口：左侧源代码管理侧栏、右侧带标签页和面包屑的 diff 编辑区、底部状态栏，并使用 VS Code 默认的 Dark Modern 深色配色，让用户在熟悉的布局里完成查看和提交。

## ADDED Requirements

### Requirement: 整体布局

打开仓库后，窗口 SHALL 由三部分组成：左侧侧栏、右侧编辑区、底部贯通整个窗口宽度的状态栏。侧栏与编辑区之间 SHALL 可拖动调整宽度，侧栏默认宽度约 300 像素。

#### Scenario: 打开仓库后的布局

- **WHEN** 用户打开一个有改动的仓库
- **THEN** 窗口左侧是源代码管理侧栏，右侧是编辑区，底部是状态栏

#### Scenario: 调整侧栏宽度

- **WHEN** 用户拖动侧栏与编辑区之间的分隔线
- **THEN** 侧栏宽度随之变化，编辑区占据剩余宽度

### Requirement: 源代码管理侧栏

侧栏自上而下 SHALL 包含：标题行（文字「SOURCE CONTROL」，右侧依次为「提交」✓、「刷新」、「…」更多操作按钮）；提交信息输入框；「✓ 提交」按钮（右侧带下拉箭头）；文件分组列表。分组依次为「合并更改」「暂存的更改」「更改」，没有文件的组 SHALL 不显示；每个组标题 SHALL 可折叠，并在右侧显示文件数量徽标，鼠标悬停时显示组级操作按钮。

文件行 SHALL 显示：文件图标（统一的通用文件图标）、文件名、所在目录（较暗的颜色）、右侧的状态字母。状态字母与颜色 SHALL 采用 VS Code 的约定：M 修改、A 新增、D 删除、R 重命名、C 复制、U 未跟踪、! 冲突。鼠标悬停时 SHALL 在状态字母左侧显示该行的操作按钮。当前打开的文件行 SHALL 高亮。

#### Scenario: 文件行内容

- **WHEN** 「更改」组里有修改过的 `src/app/main.rs`
- **THEN** 该行显示 `main.rs`、较暗的 `src/app`，以及右侧黄色的 `M`

#### Scenario: 悬停显示操作

- **WHEN** 鼠标移到「更改」组的某个文件行上
- **THEN** 行右侧出现「打开文件」「放弃更改」「暂存更改」按钮

#### Scenario: 空分组不显示

- **WHEN** 暂存区为空
- **THEN** 侧栏中不出现「暂存的更改」组

### Requirement: 编辑区

编辑区顶部 SHALL 是标签栏，打开文件后显示一个标签：文件图标、标题 `<文件名> (工作树)`（来自「更改」组）或 `<文件名> (索引)`（来自「暂存的更改」组）、状态字母、关闭按钮；标签栏右侧 SHALL 有「上一处更改」「下一处更改」「切换并排/内联视图」按钮。标签栏下方 SHALL 是路径面包屑（按目录层级显示文件路径）。其下是该文件的 diff。关闭标签或没有打开任何文件时，编辑区 SHALL 显示空白背景及简短提示。

#### Scenario: 从「更改」组打开

- **WHEN** 用户点击「更改」组的 `.env.dev`
- **THEN** 标签显示「.env.dev (工作树) M」，面包屑显示 `.env.dev`，下方是该文件暂存区与工作区的对照

#### Scenario: 切换内联视图

- **WHEN** 用户点击「切换并排/内联视图」
- **THEN** diff 在左右对照与单栏内联之间切换，当前文件保持不变

#### Scenario: 跳到下一处更改

- **WHEN** 用户点击「下一处更改」
- **THEN** diff 滚动到当前位置之后的下一处改动

### Requirement: 状态栏

状态栏 SHALL 位于窗口底部，左侧显示分支（分支图标 + 分支名）与同步入口（见 `source-control` 的「分支与同步状态」）。未打开仓库时状态栏 SHALL 不显示分支与同步信息。

#### Scenario: 状态栏内容

- **WHEN** 打开位于 `test` 分支、有未提交改动、落后上游 6 个提交的仓库
- **THEN** 状态栏左侧显示 `test*` 和 `6↓ 0↑`

### Requirement: Dark Modern 配色

系统 SHALL 固定使用与 VS Code 默认主题 Dark Modern 一致的深色配色，不跟随系统的浅色/深色设置。关键颜色 SHALL 与 VS Code 一致：编辑区背景 `#1F1F1F`、侧栏/标签栏/状态栏背景 `#181818`、分隔线 `#2B2B2B`、主要文字 `#CCCCCC`、次要文字 `#9D9D9D`、主按钮 `#0078D4`、输入框背景 `#313131`、当前标签顶边 `#0078D4`。

#### Scenario: 系统为浅色模式

- **WHEN** macOS 处于浅色外观，用户启动应用
- **THEN** 应用仍以 Dark Modern 深色配色显示
