## Why

用户用 Claude / Codex CLI 写代码，看 Whit 里的改动时经常需要顺手改几行，或者看一眼没被改动的文件。现在只能回到 VS Code 去做。Whit 的目标是精简版 VS Code，这一期补上 VS Code 最基本的一块：左侧资源管理器列出项目文件，点开后在右侧编辑、保存。

这改变了项目边界：`openspec/config.yaml` 原来把「编辑文件」列为不做。这次是用户明确提出的，本变更会同步改写 config 里的边界描述。

## What Changes

- **活动栏**：窗口最左侧新增 VS Code 的活动栏，有「资源管理器」和「源代码管理」两个图标，点击切换侧栏视图。打开仓库后默认显示源代码管理，与现在一致。
- **资源管理器**：以树形列出仓库根目录下的文件和文件夹。展开文件夹时才读取它的内容。文件夹排在前面，名称按自然顺序排列且不区分大小写。被 `.gitignore` 忽略的条目照常显示，但颜色变暗。`.git`、`.DS_Store` 等不显示。文件名按 git 状态着色并显示状态字母，文件夹取子树里优先级最高的颜色。切换标签时自动展开并选中当前文件。
- **多标签编辑区**（**BREAKING**，原来只有一个 diff 标签）：
  - 编辑区改为可以同时打开多个标签，文件标签和 diff 标签放在同一排。
  - 单击打开的是预览标签（标题为斜体），再单击别的文件会替换它；编辑、双击标签或保存后转为普通标签。
  - 同一文件只开一个标签。关闭标签后激活最近使用的标签。
- **文件编辑**：
  - 带语法高亮、行号、查找的代码编辑器，⌘S 保存。
  - 有未保存修改的标签显示圆点，悬停时圆点变成关闭按钮。撤销回到保存时的状态后，圆点消失。
  - 关闭有未保存修改的标签时询问「保存 / 不保存 / 取消」。关闭文件夹、切换仓库、退出应用时同样询问。
  - 二进制文件和非 UTF-8 文件不打开编辑，标签里显示原因。
  - 状态栏右侧显示光标所在的行和列。
- **文件变化监听**：
  - 用 `notify`（macOS 上是 FSEvents）监听仓库目录，取代「窗口重新获得焦点时刷新」。
  - 磁盘变化会刷新已展开的文件夹、打开的文件和源代码管理的改动列表。
  - 打开的文件如果没有未保存修改，就静默重载，撤销历史保留；如果有未保存修改，就不重载，保存时提示文件已在磁盘上被修改，询问是否覆盖。
  - 文件被删除后，标签标题显示删除线。
- **源代码管理的联动**：
  - 文件行上的「打开文件」按钮改为在应用内打开文件标签，不再用系统默认程序打开。
  - 点击改动文件打开的 diff 标签也是预览标签。
  - 保存文件后改动列表随之更新。
- **gpui-base 补丁**：编辑器的撤销栈目前不对外提供版本号。按 VS Code 的规则判断「是否有未保存修改」需要这个版本号，因此在 gpui-base 加一个补丁：暴露版本号，并在保存时切断撤销合并。补丁存入 `patches/`。

## 不做的事

- 资源管理器里新建、重命名、删除、移动文件，拖拽，右键菜单，多选。
- 紧凑目录（只有一个子目录的链合并成 `a/b/c` 一行）。
- 编辑 diff 标签右侧的工作区内容（VS Code 允许在 diff 编辑器里直接改），diff 标签仍是只读的。
- 保存冲突时的「比较」按钮，以及编码选择、换行符切换、另存为、自动保存、保存时格式化。
- 编辑器行号旁的 git 改动标记、小地图、分屏、固定标签、拖动标签排序、标签数量上限。
- 快速打开文件（⌘P）、全局搜索替换、LSP（补全、跳转、诊断）、命令面板。
- 新建未命名文件。

## Capabilities

### New Capabilities

- `explorer`：活动栏与侧栏视图切换；资源管理器文件树的内容、按需加载、排序、排除和忽略规则、git 状态着色、自动定位当前文件，以及单击和双击的行为。
- `file-editor`：多标签编辑区（预览标签、去重、关闭后激活最近使用的标签、未保存圆点），文件的打开、编辑、保存，未保存修改的判定，关闭时的保存询问，二进制和非 UTF-8 文件的处理，从源代码管理文件行的「打开文件」在应用内打开（现有规格只列出这个按钮，没有规定它的行为，所以作为新增条目）。
- `file-watching`：监听仓库目录的变化，驱动文件树、打开的文件和源代码管理改动列表的刷新；打开的文件被外部修改或删除时的处理，以及保存时的冲突提示。

### Modified Capabilities

- `workbench-layout`：「整体布局」新增活动栏，侧栏可以切换视图；「编辑区」从单个 diff 标签改为多标签，标签样式（预览斜体、未保存圆点）以及只对 diff 标签显示的工具按钮；「状态栏」右侧新增行和列。
- `worktree-diff`：「点击文件打开 diff」改为以预览标签打开，不再替换唯一的标签；「刷新」的时机去掉「窗口重新获得焦点时」，改为文件变化触发；刷新后文件已不在原分组时，只处理对应的 diff 标签。
- `open-repository`：「再次打开会替换当前仓库」和「关闭文件夹」在有未保存修改的标签时，先询问是否保存。

## Impact

- **代码**：
  - `src/workbench.rs`：`Repository` 的单个 `open` 和 `diff` 改为标签组，删除窗口激活时的刷新。
  - `src/workbench/editor.rs`：重写为多标签。
  - 新增资源管理器、活动栏、文件缓冲区、文件监听的模块。
  - `src/workbench/scm_panel.rs`：「打开文件」按钮的行为。
  - `src/workbench/status_bar.rs`：行和列。
  - `src/git/read.rs`：`git status` 增加 `--ignored`。
  - `src/lib.rs`：⌘S、⌘W 快捷键和退出前的保存询问。
- **依赖**：
  - 新增 `notify`，用最新的稳定版 8.x，9.0 还是预发布版。
  - vendor `gpui-base` 并加一个撤销版本号的补丁，`[patch.crates-io]` 多一行；gpui-kit 升级时要重新应用这个补丁。
- **测试**：`src/workbench/tests.rs` 中依赖「单标签」和「激活时刷新」的用例需要改写，`tests/visual.rs` 的截图需要更新。
- **配置**：`openspec/config.yaml` 的功能边界描述。
