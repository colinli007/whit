## Why

用户用 Claude / Codex CLI 写代码，只需要一个快速、只读地看清「AI 刚改了什么」的桌面工具。现有 IDE（包括删掉 AI 的 Zed 分支）功能太多、启动和占用都偏重，这一期先做出能日常使用的最小闭环：打开文件夹，左右对照看工作区里所有未提交的改动。

## What Changes

- 新建桌面应用 diffview（临时名），Rust 单 crate。
- 打开文件夹：菜单「打开文件夹…」（cmd-O）、启动时的空状态按钮、命令行参数三种入口；文件夹在仓库子目录里时自动定位到仓库根目录。
- 工作区改动：列出相对 HEAD 的所有未提交改动（已暂存 + 未暂存 + 未跟踪文件），显示状态（新增 / 修改 / 删除 / 重命名）和增删行数。
- 左右对照 diff：所有改动文件在右侧一个连续可滚动的视图里展示，左侧点文件跳到对应位置；改动行内做词级高亮；未改动的行默认折叠，只露出改动上下 3 行，可点开展开。
- 刷新：窗口重新获得焦点时自动刷新，另有手动刷新（cmd-R）。
- 打包：产出可安装的 macOS `.app` 与 `.dmg`。

## 不做的事

- 提交历史、分支对比（第 2 期）。
- 语法高亮、监听文件变化自动刷新（第 3 期）。语法高亮在所用组件里只是一个开关，但会显著增加编译体积，留到第 3 期按需开启。
- 任何写操作：暂存 / 取消暂存 / 提交 / 还原 / 解决冲突。
- 编辑文件、终端、搜索、LSP、插件、设置界面、多窗口、多仓库标签页。
- 区分「已暂存」和「未暂存」两份 diff：这一期只看相对 HEAD 的最终结果。
- 代码签名公证与自动更新（只做本机可用的临时签名）。
- Windows / Linux 打包（框架支持，但这一期不验证）。

## Capabilities

### New Capabilities

- `open-repository`: 选择文件夹、定位 git 仓库根目录，以及不是仓库、找不到 git 等情况的提示。
- `worktree-diff`: 列出工作区相对 HEAD 的全部未提交改动，并以左右对照方式展示，包括折叠展开、词级高亮、跳转和刷新。

### Modified Capabilities

（无，新项目）

## Impact

- 新仓库 `~/Desktop/xwm/diffview`，新增 Rust crate 与打包配置。
- 依赖：`gpui-kit` 0.9.1（总包，带入 gpui-component 0.9.1 与 gpui-pre 0.3.12）、`anyhow`、`log` 等；开发依赖 `tempfile`（测试里建临时仓库）。打包工具 `cargo-packager`（命令行工具，不进运行时依赖）。
- 运行时要求：本机装有 `git`。
- 构建要求：macOS 需要 Xcode 的 Metal Toolchain（gpui 编译着色器）。
